# 678. Valid Parenthesis String

## Pattern

Greedy + Range of Possible Balances

## Approach

1. Normally, for a valid parenthesis string, we keep track of the number of unmatched `(`.

2. The problem is `*`.

   `*` can represent:

   `(`

   `)`

   or

   empty string

3. Instead of deciding exactly what every `*` represents, keep a RANGE of possible open-parenthesis counts.

4. Maintain:

   low = minimum possible number of unmatched `(`

   high = maximum possible number of unmatched `(`

5. For `(`:

   Both minimum and maximum increase:

   low++

   high++

6. For `)`:

   Both decrease:

   low--

   high--

7. For `*`:

   If we treat it as `)`:

   low--

   If we treat it as `(`:

   high++

   Therefore:

   low--
   high++

8. `low` cannot be negative because we cannot have fewer than zero unmatched `(`:

   low = max(low, 0)

9. If `high < 0`, even the most optimistic interpretation has too many `)`.

   Therefore, return `false`.

10. After processing the entire string, we need to be able to have exactly zero unmatched `(`.

   Therefore:

   return low == 0

## Time Complexity

O(n)

- We traverse the string once.

## Space Complexity

O(1)

- We only maintain `low` and `high`.

## Interview Note

- Think **"I don't need to know exactly what `*` is; I only need the range of possible open brackets."**
- `low` = minimum possible open brackets.
- `high` = maximum possible open brackets.

### Character transitions

`(`:

   low++
   high++

`)`:

   low--
   high--

`*`:

   low--
   high++

- After every character:

   high < 0 → impossible

   low = max(low, 0)

- At the end:

   low == 0 → valid

## Mental Model

Possible open counts:

        [ low ---------------- high ]

        `*` makes the range wider

        `(` shifts the range up

        `)` shifts the range down

        ↓

If `high < 0`

        ↓

No possible interpretation works

        ↓

false

At the end:

        low == 0

        ↓

Some interpretation has exactly
zero unmatched `(`

        ↓

true

## Key Idea

**Don't choose what `*` means immediately.**

Track:

**minimum possible balance + maximum possible balance**
