# 1899. Merge Triplets to Form Target Triplet

## Pattern

Greedy

## Approach

1. We want to form:

   target = [x, y, z]

2. The merge operation takes the maximum of each position.

   [a,b,c] + [d,e,f]

   becomes:

   [max(a,d), max(b,e), max(c,f)]

3. Because we only take maximums, a triplet containing a value greater than the target can NEVER be used.

   For example:

   target = [5, 5, 5]

   triplet = [6, 3, 5]

   The `6` can never become `5`.

4. Therefore, ignore every triplet where:

   t[0] > target[0]
   OR
   t[1] > target[1]
   OR
   t[2] > target[2]

5. For every valid triplet, keep the maximum value seen at each position:

   a = max(a, t[0])
   b = max(b, t[1])
   c = max(c, t[2])

6. At the end, check whether:

   [a,b,c] == target

7. If all three positions can reach the target without exceeding it, we can merge those triplets to form the target.

## Time Complexity

O(n)

- We inspect every triplet once.
- Each triplet has exactly 3 values.

## Space Complexity

O(1)

- We only store the maximum value for each of the 3 positions.

## Interview Note

- Think **"Can this triplet safely contribute to the target?"**
- If ANY value is greater than the corresponding target value → ignore it.
- Why?

   Merge uses `max`.

   So once a value becomes too large, it can never decrease.

- For the remaining safe triplets, greedily collect the maximum value for each position.

- Key idea:

   TOO LARGE → DISCARD

   SAFE → TAKE MAX

- At the end:

   collected == target → true

   otherwise → false
