# 763. Partition Labels

## Pattern

Greedy + Two Pointers

## Approach

1. We need to split the string into as many parts as possible such that every character appears in at most one part.

2. First, find the last occurrence of every character:

   last[c] = last index where character c appears

3. Traverse the string from left to right.

4. Maintain:

   start = beginning of the current partition

   end = farthest index the current partition must reach

5. For every character `s[i]`, extend the current partition to include its last occurrence:

   end = max(end, last[s[i] - 'a'])

6. Why?

   If a character appears again later, we cannot end the current partition before that occurrence.

7. When:

   i == end

   we know every character seen in the current partition has its last occurrence inside the partition.

8. Therefore, we can safely close the partition:

   ans.push_back(end - start + 1)

9. Start the next partition:

   start = i + 1

10. Return the partition sizes.

## Time Complexity

O(n)

- One pass to find the last occurrence of every character.
- One pass to construct the partitions.

## Space Complexity

O(1)

- The `last` array has only 26 entries because the string contains lowercase English letters.

## Interview Note

- Think **"How far must my current partition extend?"**
- The key is the **last occurrence** of every character.
- For every character inside the current partition:

   end = max(end, last[s[i]])

- We can only close the partition when:

   i == end

- This gives the **smallest valid partition**, which is what we want because the problem asks for as many partitions as possible.

## Mental Model

Start partition

        ↓

See character `c`

        ↓

Find its LAST occurrence

        ↓

Extend `end`

        ↓

Keep scanning

        ↓

i == end?

   NO → continue

   YES → close partition

        ↓

Start next partition

## Key Idea

**Every character must stay completely inside one partition.**

Therefore:

**last occurrence → determines partition boundary**

**When current index reaches the boundary → partition is complete.**
