# 355. Design Twitter

## Pattern

HashMap + HashSet + Max Heap

## Intuition

Each user has their own stream of tweets ordered by time.

For `getNewsFeed`, we need the 10 most recent tweets from:

- The user themselves
- Everyone they follow

This is essentially **Merge K Sorted Lists**.

Each user's tweets are already sorted by time, so use a Max Heap to merge these streams and retrieve the newest tweets first.

## Approach

1. Store every user's tweets with:
   - `tweetId`
   - `timestamp`

2. Store follow relationships using a HashSet:

   `user → set of followees`

3. When a user posts a tweet:
   - Add it to their tweet list.
   - Give it an increasing timestamp.

4. For `getNewsFeed`:
   - Put the latest tweet of the user and every followee into a Max Heap.
   - Heap is ordered by timestamp.
   - Pop the newest tweet.
   - Add it to the feed.
   - Push that same user's previous tweet into the heap.
   - Repeat until we have 10 tweets or the heap is empty.

5. For `follow`:
   - Add the followee to the follower's set.

6. For `unfollow`:
   - Remove the followee from the set.

## Time Complexity

`postTweet` → O(1) average

`follow` → O(1) average

`unfollow` → O(1) average

`getNewsFeed` → O(F log F + 10 log F)

- `F` = number of users whose tweets need to be considered.
- We initially add at most one tweet per relevant user.
- We only extract at most 10 tweets.

## Space Complexity

O(T + F)

- `T` = total number of tweets.
- `F` = total follow relationships.

## Interview Note

- Think **"Twitter Feed = Merge K Sorted Lists."**
- Each user's tweets form one sorted stream.
- Max Heap gives the newest available tweet.
- After popping a tweet, push that user's previous tweet.
- Only retrieve 10 tweets, so we don't need to merge everything.
- Use a timestamp instead of relying on tweet IDs because tweet IDs do not necessarily represent chronological order.

## Mental Model

Suppose:

   User A: 10 → 7 → 3
   User B: 9 → 6 → 2
   User C: 8 → 5 → 1

Initially put the latest tweet from each user into the Max Heap:

   Heap = 10, 9, 8

Pop 10:

   Feed = [10]

Push A's previous tweet:

   Heap = 9, 8, 7

Pop 9:

   Feed = [10, 9]

Push B's previous tweet:

   Heap = 8, 7, 6

Continue until 10 tweets are collected.

## Key Idea

**Each user's tweets = sorted list**

**Max Heap = merge all relevant tweet streams**

**Pop newest → add previous tweet from same user → repeat**

This is essentially:

**Merge K Sorted Lists + Social Graph (following relationships).**
