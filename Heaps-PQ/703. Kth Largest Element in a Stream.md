# 703. Kth Largest Element in a Stream

## Pattern

Min Heap of Size K

## Intuition

We continuously receive new numbers and need to return the kth largest element after every insertion.

We don't need to store all elements in sorted order.

Maintain only the `k` largest elements using a Min Heap.

The smallest among these `k` elements is exactly the kth largest overall.

Therefore:

   Heap size = k
   Heap top = kth largest

## Approach

1. Create a Min Heap.

2. For every number:
   - Insert it into the heap.
   - If heap size becomes greater than `k`, remove the smallest element.

3. Keep doing this for every new number added to the stream.

4. The top of the heap is always the kth largest element.

## Time Complexity

O(log k) per `add()`

- Each insertion takes O(log k).
- At most one element is removed.

## Space Complexity

O(k)

- The heap stores only the `k` largest elements.

## Interview Note

- Think **"Keep the top k elements, and let the smallest of them sit at the top."**
- Kth largest → Min Heap.
- Always maintain heap size `k`.
- `pq.top()` = kth largest.

## Mental Model

For `k = 3`:

Stream:

   4, 5, 8, 2, 10

After processing:

   4 → heap [4]
   5 → heap [4,5]
   8 → heap [4,5,8]

Top = 4 → 3rd largest

Add 2:

   heap [2,4,5,8]
        ↓
   remove 2
   heap [4,5,8]

Top = 4

Add 10:

   heap [4,5,8,10]
        ↓
   remove 4
   heap [5,8,10]

Top = 5 → 3rd largest

## Key Idea

**Min Heap + size K**

If heap size > K:

   pop()

Then:

   heap.top() = kth largest
