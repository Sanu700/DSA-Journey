# 1046. Last Stone Weight

## Pattern

Max Heap / Priority Queue

## Intuition

At every step, we need to smash the two heaviest stones.

A Max Heap always gives us the largest stone in O(log n).

After smashing:

- If both stones are equal, both disappear.
- Otherwise, the difference remains and is pushed back into the heap.

## Approach

1. Put all stones into a Max Heap.

2. While at least two stones remain:
   - Pop the largest stone `x`.
   - Pop the second largest stone `y`.
   - If `x != y`, push `x - y` back into the heap.
   - If `x == y`, both stones are destroyed.

3. When fewer than two stones remain:
   - If the heap is empty, return `0`.
   - Otherwise, return the remaining stone.

## Time Complexity

O(n log n)

- Building and repeatedly updating the heap takes O(n log n) overall.

## Space Complexity

O(n)

- The Max Heap can contain up to `n` stones.

## Interview Note

- Think **"Repeatedly take the two maximum elements."**
- This directly suggests a **Max Heap**.
- Don't modify the original `stones` vector.
- Manipulate only the heap.

## Mental Model

For:

   [2, 7, 4, 1, 8, 1]

Max Heap gives:

   8, 7

Smash:

   8 - 7 = 1

Push `1` back.

Then repeat:

   4, 2 → 2
   2, 1 → 1
   1, 1 → destroyed

No stones remain.

Answer = 0

## Key Idea

**Max Heap → pop largest 2 → smash → push difference if non-zero.**
