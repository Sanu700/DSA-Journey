# 3. Longest Substring Without Repeating Characters

## Pattern
Sliding Window + HashSet

## Approach

1. Initialize two pointers:
   - `left = 0`
   - `right = 0`
2. Maintain an `unordered_set<char>` to store characters in the current window.
3. Expand the window by moving `right`.
4. If the current character already exists in the set:
   - Remove characters from the left until the duplicate is removed.
5. Insert the current character into the set.
6. Update the maximum window size.
7. Return the maximum length.

## Time Complexity
O(n)

## Space Complexity
O(min(n, k))

- `k` = character set size.

## Interview Note
- Think **"Expand the window until it becomes invalid, then shrink until it's valid again."**
- Use a `HashSet` to detect duplicates in O(1).
- Common mistake: Restarting the window when a duplicate is found. Instead, **shrink only as much as needed**.
