# 21. Merge Two Sorted Lists

## Pattern

Two Pointers + Linked List

## Intuition

We have two sorted linked lists.

At every step, compare the current nodes of both lists and attach the smaller node to the result.

Because both lists are already sorted, the smaller current node is always the next node that belongs in the merged list.

## Approach

1. Create a dummy node to act as the starting point of the merged list.

2. Maintain a `curr` pointer that represents the last node in the merged list.

3. While both lists are non-empty:

   - Compare `list1->val` and `list2->val`.
   - Attach the smaller node to `curr->next`.
   - Move the selected list pointer forward.
   - Move `curr` forward.

4. Once one list becomes empty, attach the remaining list directly.

5. Return `dummy.next`.

## Time Complexity

O(m + n)

- Every node from both lists is processed exactly once.

## Space Complexity

O(1)

- We only use a few pointers.
- No new nodes are created apart from the dummy node.

## Interview Note

- Think **"Compare → Attach → Move."**
- Since both lists are already sorted, always take the smaller current node.
- `curr->next` should point to the **node**, not its value.

   `curr->next = list1` → correct

   `curr->next = list1->val` → wrong

- After attaching a node, move that list:

   `list1 = list1->next`

   or

   `list2 = list2->next`

- The dummy node makes handling the head of the merged list much easier.

## Mental Model

list1: 1 → 3 → 5

list2: 2 → 4 → 6

Compare:

   1 vs 2 → take 1

   3 vs 2 → take 2

   3 vs 4 → take 3

   5 vs 4 → take 4

   5 vs 6 → take 5

Then attach the remaining:

   6

Result:

   1 → 2 → 3 → 4 → 5 → 6

## Key Idea

**Both lists are sorted → always attach the smaller current node.**
