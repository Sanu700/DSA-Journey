# 25. Reverse Nodes in k-Group

## Pattern

Linked List + Iterative Reversal

## Intuition

We need to reverse the linked list in groups of `k`.

Only reverse a group if it contains exactly `k` nodes.

If fewer than `k` nodes remain at the end, leave them unchanged.

The key is to keep track of:

- Node before the current group
- kth node of the group
- Node after the group

## Approach

1. Create a dummy node before the head.

2. Maintain `groupPrev`, which points to the node immediately before the current group.

3. Find the `kth` node starting from `groupPrev`.

4. If a complete group of `k` nodes doesn't exist, stop.

5. Store the node after the group as `groupNext`.

6. Reverse the current group using the standard linked-list reversal technique.

7. Connect the previous part of the list to the reversed group.

8. Move `groupPrev` to the original beginning of the group, which is now its end.

9. Repeat until fewer than `k` nodes remain.

10. Return `dummy.next`.

## Time Complexity

O(n)

- Each node is visited a constant number of times.

## Space Complexity

O(1)

- Only pointers are used.
- No extra list or recursion is required.

## Interview Note

- Think **"Find k → Reverse k → Connect → Repeat."**
- The important pointers are:
  - `groupPrev` → node before group
  - `kth` → last node of group
  - `groupNext` → node after group
- If fewer than `k` nodes remain, don't reverse them.
- The dummy node makes handling the first group much easier.

## Mental Model

For:

   1 → 2 → 3 → 4 → 5

and `k = 2`:

First group:

   1 → 2

becomes:

   2 → 1

Then:

   3 → 4

becomes:

   4 → 3

The remaining `5` stays unchanged.

Result:

   2 → 1 → 4 → 3 → 5

## Key Idea

**For every group:**

   Find k nodes
        ↓
   Reverse them
        ↓
   Connect them
        ↓
   Move to next group

**Incomplete final group → leave it as-is.**
