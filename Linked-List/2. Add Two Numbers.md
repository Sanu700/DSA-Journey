# 2. Add Two Numbers

## Pattern

Linked List Traversal + Carry

## Intuition

The numbers are stored in reverse order, so the head represents the units digit.

This means we can add the two numbers exactly like normal addition:

   digit + digit + carry

For every position:

   sum = l1 digit + l2 digit + carry

The new digit is:

   sum % 10

The carry is:

   sum / 10

A dummy node makes building the result list easy.

## Approach

1. Create a dummy node to build the answer list.

2. Maintain a `carry` variable starting at 0.

3. Traverse both linked lists while either list still has nodes or a carry remains.

4. Add the current digits and carry.

5. Create a new node containing `sum % 10`.

6. Update carry using `sum / 10`.

7. Move whichever input pointers are available.

8. Continue until both lists are exhausted and carry becomes 0.

9. Return `dummy.next`.

## Time Complexity

O(max(n, m))

- Each node from both lists is processed once.

## Space Complexity

O(max(n, m))

- The result list requires at most one node per digit, plus a possible final carry.

## Interview Note

- Think **"Normal addition, but traverse the linked lists."**
- `sum % 10` → current digit
- `sum / 10` → carry
- Use a dummy node to construct the result.
- The loop must also continue when `carry != 0`.

## Mental Model

For:

   2 → 4 → 3
   5 → 6 → 4

This represents:

   342 + 465

Add from left to right in the lists:

   2 + 5 = 7
   4 + 6 = 10 → digit 0, carry 1
   3 + 4 + 1 = 8

Result:

   7 → 0 → 8

which represents:

   807

## Key Idea

**At every node:**

   sum = digit1 + digit2 + carry

**Then:**

   digit = sum % 10
   carry = sum / 10
