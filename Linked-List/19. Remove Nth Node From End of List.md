# 19. Remove Nth Node From End of List

## Pattern

Fast & Slow Pointers + Dummy Node

## Intuition

We need to remove the `nth` node from the end.

Instead of calculating the length of the list, maintain a gap of `n` nodes between `fast` and `slow`.

When `fast` reaches the end, `slow` will be exactly at the node BEFORE the node we want to remove.

## Approach

1. Create a dummy node before the head.

   dummy → head

   This makes removing the actual head easier.

2. Initialize both pointers at the dummy:

   slow = dummy

   fast = dummy

3. Move `fast` exactly `n` nodes forward.

   This creates an `n`-node gap between `slow` and `fast`.

4. Move both pointers together until `fast` reaches the last node:

   slow → slow->next

   fast → fast->next

5. Now `slow->next` is the node that needs to be removed.

6. Skip that node:

   slow->next = slow->next->next

7. Return:

   dummy.next

## Time Complexity

O(n)

- We traverse the linked list once.

## Space Complexity

O(1)

- Only a few pointers are used.

## Interview Note

- Think **"Create an n-node gap, then move both pointers together."**
- Use a dummy node because the node to remove could be the head.
- The important sequence is:

   1. `fast = dummy`
   2. Move `fast` `n` steps
   3. Move `slow` and `fast` together
   4. `slow->next` is the node to delete
   5. Skip it

- The dummy node handles the edge case where:

   n == length of the list

   In that case, `slow` remains at the dummy and we remove the original head.

## Mental Model

List:

   1 → 2 → 3 → 4 → 5

n = 2

After creating the gap:

   slow
     ↓
   dummy → 1 → 2 → 3 → 4 → 5
                         ↑
                       fast

Move both:

   dummy → 1 → 2 → 3 → 4 → 5
                     ↑       ↑
                   slow    fast

Therefore:

   slow->next = 4

Remove it:

   1 → 2 → 3 → 5

## Key Idea

**Don't find the middle.**

**Create an `n`-node gap between fast and slow.**

When `fast` reaches the end:

**slow → node BEFORE the node to remove.**
