# 138. Copy List with Random Pointer

## Pattern

HashMap + Linked List

## Intuition

We need to create a completely independent copy of the linked list.

The `next` pointer is easy because it follows the normal linked-list order.

The difficult part is the `random` pointer because it can point to ANY node in the list.

So we maintain a mapping:

original node → copied node

Then whenever we need to connect a copied node's pointer, we can find the corresponding copied node using the HashMap.

## Approach

1. Create a HashMap:

   original node → copied node

2. First traversal:

   Traverse the original list and create a new node for every original node.

   Store each mapping in the HashMap.

3. At this point, every copied node exists, but their `next` and `random` pointers are not connected yet.

4. Second traversal:

   For every original node, connect the corresponding copied node.

   The copied `next` pointer should point to:

   map[curr->next]

   The copied `random` pointer should point to:

   map[curr->random]

5. Move through the original list while using the map to connect the copied nodes.

6. Return:

   map[head]

## Time Complexity

O(n)

- First traversal creates all copied nodes.
- Second traversal connects all pointers.

## Space Complexity

O(n)

- The HashMap stores a mapping for every node.

## Interview Note

- Think **"Create everything first, connect everything second."**
- The key mapping is:

   original → copy

- First pass:

   Create nodes + store mapping

- Second pass:

   Connect `next` + `random`

- For `random`, don't try to find the target manually.

   curr->random
        ↓
   map[curr->random]
        ↓
   copied random node

- You don't actually need a dummy node because the copied head is simply:

   map[head]

## Mental Model

Original:

   A → B → C

   A.random → C
   B.random → A
   C.random → B

After first pass:

   A → A'
   B → B'
   C → C'

Using the map:

   A → A'
   B → B'
   C → C'

Then connect:

   A'.next → B'
   A'.random → C'

   B'.next → C'
   B'.random → A'

   C'.random → B'

## Key Idea

**HashMap = original node → copied node**

**Pass 1 → create copies**

**Pass 2 → connect next + random**

This is the cleanest O(n) time, O(n) space solution.
