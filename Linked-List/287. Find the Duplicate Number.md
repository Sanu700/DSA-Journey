# 287. Find the Duplicate Number

## Pattern

Floyd's Cycle Detection / Fast & Slow Pointers

## Intuition

Treat the array like a linked list.

For every index `i`, the next node is:

   nums[i]

Because numbers are in the range `1` to `n`, every value points to another valid index.

Since there are `n + 1` numbers but only `n` possible values, at least one value is duplicated.

The duplicate creates a cycle in this implicit linked list.

Floyd's Cycle Detection can find the entrance of that cycle.

## Approach

1. Initialize `slow` and `fast` at `nums[0]`.

2. Move:
   
   slow → one step
   
   fast → two steps

3. Continue until `slow == fast`.

   This means both pointers have entered the cycle.

4. Reset `slow` to `nums[0]`.

5. Move both pointers one step at a time.

6. The point where they meet is the duplicate number.

7. Return that value.

## Time Complexity

O(n)

- Floyd's algorithm traverses the array a constant number of times.

## Space Complexity

O(1)

- Only two pointers are used.
- No HashSet or extra array is needed.

## Interview Note

- Think **"Array → Linked List → Cycle → Floyd's Algorithm."**
- `nums[i]` acts like the `next` pointer.
- The duplicate number is the **entrance of the cycle**.
- Don't use sorting or a HashSet if the interviewer expects O(1) extra space.

## Mental Model

Example:

   nums = [1, 3, 4, 2, 2]

Think of indices as nodes:

   0 → 1 → 3 → 2 → 4 → 2
                   ↑     ↓
                   └─────┘

The duplicate `2` causes the cycle.

Floyd's algorithm finds the cycle entrance:

   2

Therefore the duplicate number is `2`.

## Key Idea

**Treat `nums[i]` as the next pointer.**

Duplicate value → cycle entrance.

**Fast/Slow → detect cycle → reset one pointer → meet at duplicate.**
