# 323. Number of Connected Components in an Undirected Graph

## Pattern
Graph + DFS + Connected Components

## Intuition

This is basically the same DFS used in **Graph Valid Tree**.

The difference is:

### Graph Valid Tree

We start DFS from `0` and ask:

> Did we visit every node?

### Number of Connected Components

We go through every node and ask:

> Have I already visited this node?

If not, we found a **new connected component**.

```text
0 — 1 — 2

3 — 4

5
```

There are:

```text
Component 1 → 0,1,2
Component 2 → 3,4
Component 3 → 5
```

Answer:

```text
3
```

---

## Approach

### 1. Build an undirected adjacency list

```cpp
adj[u].push_back(v);
adj[v].push_back(u);
```

---

### 2. Create visited array

```cpp
vector<bool> visited(n, false);
```

---

### 3. Loop through every node

```cpp
for(int i = 0; i < n; i++) {

    if(!visited[i]) {

        count++;

        dfs(i, adj, visited);
    }
}
```

Every time we find an unvisited node:

```text
unvisited node
      ↓
new component
      ↓
count++
      ↓
DFS
      ↓
mark entire component visited
```

---

## DFS

```cpp
void dfs(int node,
         vector<vector<int>>& adj,
         vector<bool>& visited) {

    visited[node] = true;

    for(int nei : adj[node]) {

        if(!visited[nei]) {
            dfs(nei, adj, visited);
        }
    }
}
```

---

## Why `dfs(i)` and not `dfs(0)`?

Suppose:

```text
0 — 1

2 — 3
```

After exploring `0`, nodes `0` and `1` are visited.

When the loop reaches `2`:

```cpp
if(!visited[2])
```

we found a new component.

So we need:

```cpp
dfs(2, adj, visited);
```

not:

```cpp
dfs(0, adj, visited);
```

## Pattern

```text
Loop through every node
        ↓
Is it visited?
   ↙          ↘
 YES           NO
  ↓             ↓
skip          count++
                ↓
              DFS
                ↓
      mark entire component
```

### Key Idea

> **Every time DFS starts from an unvisited node, we have discovered one new connected component.**
