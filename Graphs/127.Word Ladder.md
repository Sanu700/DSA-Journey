# 127. Word Ladder

## Pattern
BFS + Shortest Path + String Mutation

## Intuition

Treat every word as a node in a graph.

Two words are connected if they differ by exactly **one character**.

Example:

```text
hit → hot → dot → dog → cog
```

Each transformation costs exactly `1`.

Therefore, this is an **unweighted shortest path** problem.

```text
Shortest path + unweighted graph
            ↓
           BFS
```

---

## Approach

### 1. Store all words in a set

```cpp
unordered_set<string> words(wordList.begin(), wordList.end());
```

This lets us quickly check whether a generated word exists.

---

### 2. Start BFS from `beginWord`

```cpp
queue<string> q;
q.push(beginWord);
```

Maintain the number of transformations:

```cpp
int steps = 1;
```

---

### 3. Generate all possible one-letter changes

For every position:

```cpp
for(int i = 0; i < word.size(); i++)
```

Try every letter from `a` to `z`:

```cpp
for(char ch = 'a'; ch <= 'z'; ch++)
```

Example:

```text
hot
```

Generate:

```text
aot
bot
cot
...
hat
hbt
...
hoa
hob
...
```

Only keep the generated word if it exists in the set.

---

### 4. Add valid words to BFS

```cpp
if(words.count(word)) {
    q.push(word);
    words.erase(word);
}
```

Erasing the word means:

> We've already visited this word, so don't process it again.

This prevents cycles and duplicate work.

---

### 5. First time we reach `endWord`

Because BFS explores level by level, the first time we reach `endWord`, we have found the shortest transformation.

```cpp
if(word == endWord)
    return steps + 1;
```

---

## Example

```text
beginWord = "hit"
endWord = "cog"
```

BFS:

```text
Level 1:
hit

Level 2:
hot

Level 3:
dot

Level 4:
dog

Level 5:
cog
```

Answer:

```text
5
```

---

## Why BFS?

Every transformation has equal cost:

```text
hit → hot = 1
hot → dot = 1
dot → dog = 1
dog → cog = 1
```

Therefore:

```text
Unweighted shortest path → BFS
```

Dijkstra is unnecessary because all edges have the same weight.

---

## Complexity

Let:

- `N` = number of words
- `L` = length of each word

For every word we try:

```text
L positions × 26 letters
```

So approximately:

```text
O(N × L × 26)
```

Since `26` is constant:

```text
O(N × L)
```

Space:

```text
O(N)
```

for the word set and BFS queue.

---

## Pattern Recognition

```text
Word Ladder
     ↓
Words = nodes
1-letter difference = edge
     ↓
Every edge costs 1
     ↓
Shortest path
     ↓
BFS
```

### Key Trick

> For every word, try changing each character from `a` to `z`, and keep only the generated words that exist in the dictionary.
