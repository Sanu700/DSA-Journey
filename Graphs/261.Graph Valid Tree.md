# 261. Graph Valid Tree

## Pattern
Graph + DFS + Connectivity + Edge Count

## Intuition

A graph is a valid tree if:

1. **All nodes are connected**
2. **There is no cycle**

A useful property:

```text
A tree with n nodes always has exactly n - 1 edges.
```

Therefore, we can check:

```text
edges.size() == n - 1
        +
all nodes are connected
        ↓
Valid Tree
```

We don't need to explicitly detect the cycle.

---

## Approach

### 1. Check number of edges

```cpp
if(edges.size() != n - 1)
    return false;
```

If there are:

- More than `n - 1` → there must be a cycle.
- Fewer than `n - 1` → graph cannot be fully connected.

---

### 2. Build an undirected graph

Since the graph is undirected, add both directions:

```cpp
adj[u].push_back(v);
adj[v].push_back(u);
```

---

### 3. Run DFS

Start from node `0`:

```cpp
dfs(0, adj, visited);
```

Mark every reachable node as visited.

---

### 4. Check connectivity

After DFS:

```cpp
for(int i = 0; i < n; i++) {
    if(!visited[i])
        return false;
}
```

If any node wasn't visited, the graph is disconnected.

Otherwise:

```cpp
return true;
```

---

## Example

```text
0 —— 1 —— 2
     |
     3
```

```text
n = 4
edges = 3
```

Since:

```text
edges = n - 1
3 = 4 - 1
```

and DFS from `0` reaches:

```text
0, 1, 2, 3
```

→ Valid tree ✅

---

## Complexity

### Time
```text
O(V + E)
```

- Build adjacency list: `O(E)`
- DFS: `O(V + E)`

### Space
```text
O(V + E)
```

for the adjacency list, visited array, and DFS recursion stack.

---

## Pattern Recognition

```text
Graph Valid Tree

        ↓
edges == n - 1 ?
        ↓
       YES
        ↓
DFS / BFS
        ↓
Are all nodes connected?
        ↓
YES → Valid Tree
NO  → Not a Tree
```

### Key Formula

```text
TREE = n nodes + n - 1 edges + connected
```

### Important

For this approach, you **don't explicitly detect the cycle**.

The `n - 1` edge condition combined with connectivity guarantees that there is no cycle.
