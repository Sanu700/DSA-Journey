# 1143. Longest Common Subsequence

## Pattern

2D Dynamic Programming

## Approach

1. Create a 2D `dp` array where:

   dp[i][j] = length of the LCS of the first i characters of text1 and first j characters of text2

2. Initialize the DP table with `0`.

   If either string is empty, the LCS length is `0`.

3. Traverse both strings using two pointers `i` and `j`.

4. If the current characters match:

   text1[i-1] == text2[j-1]

   then include this character in the LCS:

   dp[i][j] = dp[i-1][j-1] + 1

5. If the characters do not match, we have two choices:
   - Ignore the current character of `text1`
   - Ignore the current character of `text2`

   Take the better option:

   dp[i][j] = max(dp[i-1][j], dp[i][j-1])

6. Return:

   dp[m][n]

## Time Complexity

O(m × n)

- We compare every pair of characters from the two strings.

## Space Complexity

O(m × n)

- The 2D DP table stores the LCS result for every pair of prefixes.

## Interview Note

- Think **"What is the LCS of the first i characters of text1 and first j characters of text2?"**
- If characters match → take the character and move diagonally.
- If characters don't match → skip one character and take the maximum of top and left.
- Key transitions:

   Same character:
   
   dp[i][j] = dp[i-1][j-1] + 1

   Different character:

   dp[i][j] = max(dp[i-1][j], dp[i][j-1])

- The `i-1` and `j-1` are used because `dp[i][j]` represents the first `i` and `j` characters.
