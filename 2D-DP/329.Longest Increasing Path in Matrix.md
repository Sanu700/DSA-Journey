# 329. Longest Increasing Path in a Matrix

## Pattern

DFS + Memoization (2D Dynamic Programming)

## Approach

1. Create a `dp` matrix where:

   dp[r][c] = longest increasing path STARTING from cell (r,c)

2. From every cell, try moving in all 4 directions:

   Up
   Down
   Left
   Right

3. We can only move to a neighboring cell if its value is strictly greater:

   matrix[nr][nc] > matrix[r][c]

4. Start with:

   dp[r][c] = 1

   because the current cell itself is a path of length `1`.

5. If we can move to a larger neighboring cell, calculate:

   dp[r][c] = max(dp[r][c], 1 + dfs(nr,nc))

6. Use memoization:

   if(dp[r][c] != 0)
       return dp[r][c];

   This prevents recalculating the same cell multiple times.

7. Run DFS from every cell and keep the maximum result.

8. Return the global maximum.

## Time Complexity

O(m × n)

- Every cell is calculated only once because of memoization.
- Each cell checks only 4 neighbors.

## Space Complexity

O(m × n)

- `dp` stores the result for every cell.
- DFS recursion can use up to O(m × n) stack space in the worst case.

## Interview Note

- Think **"What is the longest increasing path STARTING from this cell?"**
- This is **DFS + DP**, also called **memoized DFS**.
- Unlike normal grid traversal, we don't need a `visited` array because we can only move to a strictly larger value.
- Strictly increasing movement means a cycle is impossible.
- Key transition:

   dp[r][c] = max(dp[r][c], 1 + dfs(nr,nc))

   when:

   matrix[nr][nc] > matrix[r][c]

- The most important distinction:

   dp[r][c] = path STARTING from this cell

   not:

   dp[r][c] = path ending at this cell
