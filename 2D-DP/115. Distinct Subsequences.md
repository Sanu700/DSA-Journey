# 115. Distinct Subsequences

## Pattern

2D Dynamic Programming + Counting Subsequences

## Approach

1. Create a `dp` array where:

   dp[i][j] = number of ways to form the first j characters of t
              using the first i characters of s

2. Initialize:

   dp[i][0] = 1

   There is exactly one way to form an empty `t`: choose nothing.

3. Traverse both strings:

   for(int i = 1; i <= m; i++)

   for(int j = 1; j <= n; j++)

4. If the current characters match:

   s[i-1] == t[j-1]

   We have two choices:

   - Use `s[i-1]` to match `t[j-1]`

     dp[i-1][j-1]

   - Skip `s[i-1]`

     dp[i-1][j]

   Therefore:

   dp[i][j] = dp[i-1][j-1] + dp[i-1][j]

5. If the characters don't match:

   s[i-1] != t[j-1]

   We cannot use `s[i-1]`, so we must skip it:

   dp[i][j] = dp[i-1][j]

6. Return:

   dp[m][n]

## Time Complexity

O(m × n)

- We check every pair of positions from `s` and `t`.

## Space Complexity

O(m × n)

- The 2D DP table stores the number of ways for every `(i, j)` pair.

## Interview Note

- Think **"How many ways can I form t using s?"**
- When characters MATCH:

   USE + SKIP

   dp[i][j] = dp[i-1][j-1] + dp[i-1][j]

- When characters DON'T MATCH:

   SKIP

   dp[i][j] = dp[i-1][j]

- The most important base case:

   dp[i][0] = 1

   because an empty string can always be formed by choosing nothing.

- Unlike LCS, we are **counting ways**, not finding the longest length.

- The key mental model:

   MATCH → take it OR skip it

   NO MATCH → skip it
