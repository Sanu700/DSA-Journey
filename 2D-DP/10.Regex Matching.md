# 10. Regular Expression Matching

## Pattern

2D Dynamic Programming

## Approach

1. Create a `dp` array where:

   dp[i][j] = whether the first i characters of s
              match the first j characters of p

2. Initialize:

   dp[0][0] = true

   Empty string matches an empty pattern.

3. A normal character matches if:

   p[j-1] == s[i-1]

   or:

   p[j-1] == '.'

4. If the characters match normally:

   dp[i][j] = dp[i-1][j-1]

   We consume one character from both `s` and `p`.

5. The tricky part is `*`.

   `*` means zero or more occurrences of the character before it.

6. If `p[j-1] == '*'`, we have two choices.

   ZERO occurrences:

   Ignore the previous character and `*`:

   dp[i][j] = dp[i][j-2]

   ONE OR MORE occurrences:

   If the character before `*` matches `s[i-1]`:

   dp[i][j] = dp[i-1][j]

7. For the one-or-more case, the previous pattern character must match:

   p[j-2] == s[i-1]

   or:

   p[j-2] == '.'

8. Initialize patterns that can match an empty string:

   a*
   a*b*
   a*b*c*

   Therefore:

   dp[0][j] = dp[0][j-2]

   when `p[j-1] == '*'`.

9. Return:

   dp[m][n]

## Time Complexity

O(m × n)

- Every `(i, j)` state is calculated once.

## Space Complexity

O(m × n)

- The 2D DP table stores all matching states.

## Interview Note

- Think **"Can the first i characters of s match the first j characters of p?"**
- Normal character or `.` → move diagonally:

   dp[i][j] = dp[i-1][j-1]

- `*` gives two choices:

   ZERO occurrences → dp[i][j-2]

   ONE OR MORE → dp[i-1][j]

- The key idea:

   `x*` means zero or more `x`

- So:

   x* → SKIP `x*`

   x* → USE `x` and keep `*` available

- Main mental model:

   NORMAL / . → DIAGONAL

   * → SKIP BOTH OR CONSUME STRING CHARACTER
