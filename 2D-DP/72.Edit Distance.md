# 72. Edit Distance

## Pattern

2D Dynamic Programming

## Approach

1. Create a `dp` array where:

   dp[i][j] = minimum number of operations needed to convert
              the first i characters of word1 into the first j characters of word2

2. Initialize the base cases:

   dp[i][0] = i

   To convert `i` characters into an empty string, we need `i` deletions.

   dp[0][j] = j

   To convert an empty string into `j` characters, we need `j` insertions.

3. Traverse both strings using `i` and `j`.

4. If the current characters are equal:

   word1[i-1] == word2[j-1]

   No operation is needed:

   dp[i][j] = dp[i-1][j-1]

5. If the characters are different, we have 3 choices:

   Delete:

   dp[i-1][j] + 1

   Insert:

   dp[i][j-1] + 1

   Replace:

   dp[i-1][j-1] + 1

6. Take the minimum:

   dp[i][j] = 1 + min(
       dp[i-1][j],
       dp[i][j-1],
       dp[i-1][j-1]
   )

7. Return:

   dp[m][n]

## Time Complexity

O(m × n)

- We compare every pair of positions from the two strings.

## Space Complexity

O(m × n)

- The 2D DP table stores the answer for every `(i, j)` pair.

## Interview Note

- Think **"How many operations are needed to convert the first i characters of word1 into the first j characters of word2?"**
- If characters MATCH → no operation → move diagonally:

   dp[i][j] = dp[i-1][j-1]

- If characters DON'T MATCH → choose the cheapest operation:

   DELETE → dp[i-1][j]

   INSERT → dp[i][j-1]

   REPLACE → dp[i-1][j-1]

- Key transition:

   dp[i][j] = 1 + min(top, left, diagonal)

- Remember the directions:

   DELETE  → TOP

   INSERT  → LEFT

   REPLACE → DIAGONAL

- The important base cases are:

   dp[i][0] = i

   dp[0][j] = j

- Main intuition:

   MATCH → KEEP

   NO MATCH → DELETE / INSERT / REPLACE
