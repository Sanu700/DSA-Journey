# 309. Best Time to Buy and Sell Stock with Cooldown

## Pattern

2D Dynamic Programming + State Machine

## Approach

1. Create a 2D `dp` array where:

   dp[i][state] = maximum profit possible on day i in that state

2. Use 3 states:

   0 → Holding a stock

   1 → Sold a stock today

   2 → Cooldown / not holding

3. Initialize day `0`:

   dp[0][0] = -prices[0]

   dp[0][1] = 0

   dp[0][2] = 0

4. For every day, calculate the three possible states.

5. If we are holding a stock, either:
   - Continue holding from yesterday.
   - Buy today after being in cooldown.

   dp[i][0] = max(dp[i-1][0], dp[i-1][2] - prices[i])

6. If we sell today, we must have been holding yesterday:

   dp[i][1] = dp[i-1][0] + prices[i]

7. If we are in cooldown, either:
   - Continue cooldown.
   - We sold yesterday.

   dp[i][2] = max(dp[i-1][2], dp[i-1][1])

8. At the end, we cannot count a state where we are still holding a stock, so return the maximum of sold and cooldown:

   max(dp[n-1][1], dp[n-1][2])

## Time Complexity

O(n)

- We process each day once.

## Space Complexity

O(n)

- The 2D DP array stores 3 states for every day.

## Interview Note

- Think **"What is my state on this day?"**
- This is similar to House Robber because the previous decision affects the current decision.
- The key difference is that we now track stock states explicitly.
- State transitions:

   HOLD → HOLD or BUY

   HOLD → SELL

   SOLD → COOLDOWN

   COOLDOWN → HOLD

- The most important idea is:

   dp[day][state]

   = maximum profit on that day while being in that state.
