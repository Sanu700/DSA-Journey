# Binary Search

## Pattern
Binary Search

## Approach

1. Set:
   ```cpp
   left = 0;
   right = n - 1;
   ```
2. While `left <= right`:
   - Calculate `mid`.
   - If `nums[mid] == target`, return `mid`.
   - If `nums[mid] < target`, search the right half.
   - Otherwise, search the left half.
3. Return `-1` if the target is not found.

## Time Complexity
O(log n)

## Space Complexity
O(1)

## Interview Note
- Use Binary Search when the search space is **sorted** or has a **monotonic property**.
- Each step eliminates roughly half of the search space.
- Use:
  ```cpp
  mid = left + (right - left) / 2;
  ```
  to avoid potential integer overflow.
