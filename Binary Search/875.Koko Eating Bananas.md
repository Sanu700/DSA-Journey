# 875. Koko Eating Bananas

## Pattern

Binary Search on Answer

## Approach

1. Search for the minimum possible eating speed `k`.
2. Set:
   ```cpp
   left = 1;
   right = max(piles);
   ```
3. For a given `k`, calculate the total hours needed:
   ```cpp
   hours += (pile + k - 1) / k;
   ```
4. If `hours <= h`:
   - `k` is possible.
   - Try a smaller speed.
5. If `hours > h`:
   - `k` is too slow.
   - Increase the speed.
6. Return `left`.

## Key Observation

- We are not searching for an element.
- We are searching for the **minimum valid eating speed**.
- If a speed works, every larger speed also works.
- This creates a **monotonic condition**, so Binary Search can be used.

## Time Complexity

- **O(n log(max(piles)))**
  - `n` piles checked for each binary search step.

## Space Complexity

- **O(1)**

## Interview Note

For each speed:

```text
hours <= h → speed works → search left
hours > h  → speed too slow → search right
```

Integer ceiling:

```cpp
(pile + k - 1) / k
```

