# 15. 3Sum

## Pattern
Sorting + Two Pointers

## Approach

1. Sort the array.
2. Iterate through the array, fixing one element `nums[i]`.
3. Skip duplicate values of `nums[i]` to avoid duplicate triplets.
4. Initialize two pointers:
   - `left = i + 1`
   - `right = n - 1`
5. Calculate `sum = nums[i] + nums[left] + nums[right]`.
6. If `sum == 0`, add the triplet to the result and skip duplicate values for both `left` and `right`.
7. If `sum < 0`, move `left++` to increase the sum.
8. If `sum > 0`, move `right--` to decrease the sum.
9. Continue until `left >= right`, then move to the next `i`.

## Time Complexity
O(n²)

## Space Complexity
O(1) Extra Space *(excluding the output array and sorting space)*

## Interview Note
- Think **"Fix one element, then solve Two Sum II on the remaining array."**
- This approach works because the array is **sorted**.
- Skip duplicates for:
  - The fixed element (`i`)
  - The left pointer
  - The right pointer
- Common mistake: Forgetting to skip duplicates, which results in repeated triplets.
