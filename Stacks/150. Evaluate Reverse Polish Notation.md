# 150. Evaluate Reverse Polish Notation

## Pattern

Stack

## Approach

1. Initialize an empty stack.
2. Traverse each token in the input.
3. If the token is a number:
   - Convert it to an integer using `stoi()`.
   - Push it onto the stack.
4. Otherwise, the token is an operator (`+`, `-`, `*`, `/`):
   - Pop the top element as the second operand (`b`).
   - Pop the next top element as the first operand (`a`).
   - Perform the operation `a operator b`.
   - Push the result back onto the stack.
5. After processing all tokens:
   - The stack contains one element, which is the final answer.

## Key Observation

- In Reverse Polish Notation, operators always use the two most recent operands.
- A **stack (LIFO)** naturally stores operands and gives them in the correct order.
- The order of operands matters for subtraction and division:
  - Always calculate `a - b` and `a / b`, not `b - a` or `b / a`.

## Time Complexity

- **O(n)**
  - Each token is processed exactly once.

## Space Complexity

- **O(n)**
  - In the worst case, all numbers are stored in the stack.

## Interview Note

- Use a **stack** whenever the next operation depends on recently seen elements.
- Push numbers into the stack.
- On encountering an operator:
  - Pop two values.
  - Perform the operation.
  - Push the result back.
- Always remember that the first popped value is the second operand.
