# 128. Longest Consecutive Sequence

## Pattern
HashSet + Sequence Detection

## Approach

1. Insert all numbers into an `unordered_set` for **O(1)** lookups.
2. Traverse each number in the set.
3. Check if `(num - 1)` exists:
   - If it exists, this number is **not** the start of a sequence, so skip it.
   - Otherwise, this number is the beginning of a sequence.
4. Starting from the sequence's first number, keep checking if `(current + 1)` exists in the set.
5. Count the length of the sequence and update the maximum length.
6. Return the maximum length found.

## Time Complexity
O(n)

- Each number is visited at most twice (once in the outer loop and once while extending a sequence).

## Space Complexity
O(n)

- HashSet stores all unique elements.

## Interview Note
- The brute-force idea is to **sort the array**, but that takes **O(n log n)**.
- The key observation is that you only need to start counting from the **first element** of a sequence.
- A number is the start of a sequence if:
  ```cpp
  !st.count(num - 1)
  ```
- Once a start is found, keep extending the sequence by checking:
  ```cpp
  st.count(current + 1)
  ```
- Common mistake: Starting a count from **every** number, which repeatedly counts the same sequence.
